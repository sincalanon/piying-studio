30 秒のショートドラマが、実測で最安 3 元（人民元）。Shisei（`dsh-shisei`）は、私が作った [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（`dsh`、Web UI 付きの DeepSeek 製オープンソースエージェントツール）のプラグインです。コードは Apache-2.0（3 つのワークフローは GPL-3.0）で公開し、`shisei.indaloop.app` の CC0 公開素材ライブラリをオンラインで読み込みます。

- **秒単位の課金、サブスクなし**：プラグインは無料で、独自のサーバーもありません。脚本作り、画像の確認、テイク選び、結合はすべてローカルで動き、費用はかかりません。お金がかかるのは映像を生成するときに借りる自分の [compshare](https://passport.compshare.cn/register?referral_code=4Lx1jWqZk3lBVdaBfXlFAc)（优云智算）GPU だけ。実測では 29.4 秒の『末班车』（終バス）が約 ¥3、40 秒の『晾衣绳』がアイドル待機込みで約 ¥5.9 でした。
- **ダメなカットだけ直す**：`@` でキャラクター・小道具・パートを指名するか、画面に丸を描いて監督と話すと、そのパートだけを撮り直します。旧バージョンにはいつでも戻せます。
- **起動と課金はすべてあなたの判断で**：LLM の監督が担当するのは絵コンテと提案だけ。GPU の起動はコードで封じてあり、画像を代わりに承認することもできません。各プロジェクトの予算上限はデフォルト ¥5 です。

## クイックスタート

<details>
<summary><b>インストール前の準備</b></summary>

- **OS**：macOS または Windows 11。[`dsh`](https://github.com/deepseek-ai/deepseek-harness) 0.2.x（Web UI）。dsh デスクトップ版ならほかに入れるものはありません。Python はデスクトップ版に同梱のものを使い、ssh と compshare 用のツールはプラグインに入っています。ffmpeg がなければ、Shisei を初めて開いたときに裏でダウンロードします。GPU マシンにログインする ssh 鍵はマシンを作るときに自動で作ります。コマンドライン版の dsh では [Node](https://nodejs.org/) 20+ と [Python](https://www.python.org/downloads/) 3.9+（Windows では `py` ランチャー付きの 64 ビット版インストーラー）も必要です。
- **音声・動画**：`ffmpeg`（お手本動画には 4.4+ が必要。なければプラグインの「設定」からワンクリックで入ります）。任意で `whisper.cpp`（セリフの照合用）。
- **監督モデル**：`dsh` に LLM を 1 つ設定します。「はじめに」ページのおすすめは Ant MaaS（蚂蚁 MaaS）の Ling-3.2-Flash（画像を読めて、無料枠あり）。
- **GPU**：[compshare](https://passport.compshare.cn/register?referral_code=4Lx1jWqZk3lBVdaBfXlFAc)（优云智算）に登録し、本人確認とチャージを済ませて、コンソールで API キーを取得。GPU は 4090 48G。
- **言語**：UI は简体中文・English・日本語・한국어。脚本と字幕は中国語です。

</details>

npm からインストールします。**版番号を必ず付けてください**。dsh に入っている pnpm は公開から 1 日たっていない版を選ばないため、`dsh-shisei` だけだと古い版が入ることがあります。

**dsh デスクトップ版**：dsh のプラグインページで「Add plugin」を押し、`dsh-shisei@0.2.2` を入力して Install。dsh を完全に終了して開き直します。デスクトップ版のプロファイルはアプリからしか変更できず、下のコマンドは使えません。

**コマンドライン版 dsh**：

```bash
# 初回のみ：dsh 内蔵の web テンプレートからプロファイルを作成。作成済みならスキップし、以下はそのプロファイル名に置き換え
dsh --profile web --from-default-profile web --dump-config >/dev/null
dsh plugin --profile web add dsh-shisei@0.2.2
dsh --profile web
```

コードを改造したい場合や最新の main を使いたい場合は、git からクローンしてインストールします。

```bash
git clone https://github.com/wquguru/dsh-shisei.git
dsh plugin --profile web add "$PWD/dsh-shisei"
```

<details>
<summary><b>プラグインのアップグレード</b></summary>

新しい版が出ると、プラグインのサイドバーに「新版」の通知が出て、「設定」上部の「版」カードがお使いの dsh に合わせた手順を示します。入れて再起動すると、アップグレードできたことを知らせます。

- **dsh デスクトップ版**：その場でのアップグレードはできません。プラグインページで dsh-shisei を先に**アンインストール**し、「Add plugin」で `dsh-shisei@新しい版` を入力して Install、dsh を完全に終了して開き直します。アンインストールを飛ばすと `This plugin is already installed` と出ます。
- **コマンドライン版 dsh**：`dsh plugin --profile web add dsh-shisei@新しい版` を実行し、dsh を再起動します。
- **新しい版が見つからない、または古い版が入った**：ミラーがまだ同期していない可能性があります。公式のレジストリに切り替えて入れ直してください（デスクトップ版はインストール欄右の Registry で選びます）。
- プロジェクト、設定、費用の台帳は `~/.dsh/shisei/` にあり、アンインストールやアップグレードでは消えません。1.0 より前は minor 版（例：0.1 → 0.2）が変わると互換性のない変更がありえます。先に[更新履歴](https://github.com/wquguru/dsh-shisei/blob/main/CHANGELOG.md)を読んでください。

</details>

`dsh` の Web UI で左サイドバーの「Shisei」を開き、「はじめに」ページに沿って監督モデル、[compshare](https://passport.compshare.cn/register?referral_code=4Lx1jWqZk3lBVdaBfXlFAc) のキー、GPU マシンを設定します。あとは同梱の練習用脚本『打烊之后』（閉店後）『末班车』（終バス）『晾衣绳』（物干しロープ）の 3 本をコピーすれば、すぐに撮り始められます。

GPU マシンの作成は約 10 分、¥1 未満です。プラグインが環境セット済みの無料の Shisei コミュニティイメージから作ります。

## 使い方

<details>
<summary><b>1. 最初のショートドラマを撮る</b></summary>

1. **脚本を書く（無料）**：「新規プロジェクト」→「ショートドラマ」でタイトルとひとことのストーリーを入力し、「監督に脚本を書いてもらう」を押します。約 7〜10 分。練習用脚本をそのままコピーしても構いません。
2. **設定画を描く（GPU）**：下部バーの価格入りボタンを押すと、確認ダイアログに GPU、アベイラビリティゾーン、単価、予想費用が並びます。「GPU を起動して撮影」を押します。
3. **画像を確認する（ローカル）**：キャスト・シーン・小道具を 1 枚ずつ「承認」するか、理由をひとこと添えて「差し戻し」。監督が理由に沿って直し、描き直します。
4. **先頭フレームを確認する（ローカル）**：約 10 秒のパートごとに先頭フレームが 1 枚。構図、顔立ちと年齢、衣装と小道具、若く見える場合の制限の 4 項目に照らし、「承認」を押すのはあなたです。
5. **動画を撮ってテイクを選ぶ（GPU）**：MiniMax H3（動画生成モデル）が 1 パートずつ撮影します。各パートの数テイクから 1 本をクリック（数字キー `1` `2`、`⌘Z` で元に戻す）。
6. **結合する（無料）**：ローカルでラウドネスを揃え、ソフト字幕を埋め込み、MP4 をダウンロード。映像に透かしはなく、MP4 のメタデータに AI 生成と記録されます。

</details>

<details>
<summary><b>2. 監督と話す</b></summary>

<p align="center"><img src="https://raw.githubusercontent.com/wquguru/dsh-shisei/67e62347992653cc4de240156d1a344ba00fbd17/docs/img/mention-light.jpg" width="800" alt="ライトテーマの『晾衣绳』（物干しロープ）プロジェクト画面。左に完成版プレーヤー、右の監督欄で @ を入力し、キャスト・シーン・小道具・パートの一覧が開いている"></p>

- プロジェクトごとに監督とのセッションが 1 つ。会話に GPU 費用はかからず、監督はページの言語で返事をします。
- `@` でキャスト・シーン・小道具・特定のパートや動画テイクを添付できます。別プロジェクトや素材ライブラリの画像も呼び出せます。
- 画面をクリックするか枠をドラッグすると、囲んだ部分がフレーム全体と一緒に監督へ届きます。
- 監督が作業中の発言は待機リストに入り、「取り消す」も「割り込む」もできます。「止める」が止めるのは監督だけで、GPU は止まりません。

> 『末班车 v2』の実測：私は不満を 3 つ書いただけ。監督が自分でフレームを抜き出して原因を探し、5 ショットを直し、見積もりを出し、確認を待ち、撮り直し、テイクを選び、結合まで。約 40 分、¥2.5。

</details>

<details>
<summary><b>3. 3 つの撮り直し方</b></summary>

<p align="center"><img src="https://raw.githubusercontent.com/wquguru/dsh-shisei/67e62347992653cc4de240156d1a344ba00fbd17/docs/img/crop-light.jpg" width="800" alt="ライトテーマのパート B「クローズアップを切り出す」ダイアログ。先頭フレームの上に 2.0× の 9:16 の枠をドラッグで置き、下部に次回撮影は約 ¥0.41、この段階では課金されないという案内が出ている"></p>

- **クローズアップを切り出す**：人物が遠すぎるとき、先頭フレームの一部を枠で囲み、鮮明なクローズアップとして描き直します（最大 6 倍）。
- **二人が横顔で向かい合う**：見つめ合うはずの 2 人が、そろって首をひねってカメラを見てしまう問題を直します。
- **衣装替え**：素材ライブラリやアップロードした衣装画像をキャストの写真にドラッグして描き直します。

どれもプロジェクトデータを変えるだけで、GPU が起動するのは次に撮影ボタンを押したときです。2026-11-10 に実機で検証済み（約 7 分 / ¥0.43）。

</details>

<details>
<summary><b>4. お手本動画：撮り方だけを学ぶ</b></summary>

ホームのストーリー入力欄の横にある「お手本動画」を押し、ローカルの動画（≤ 3 分、`ffmpeg` 4.4+ が必要）を選びます。ローカルでカットを分け、フレームを抜き出してコンタクトシートにまとめ、ビジョンモデルが固定の選択肢から各ショットのショットサイズ・カメラワーク・ライティング・人数を埋めます。それをパート単位の骨格にまとめて監督に渡します。元動画の人物、顔立ち、セリフ、映像はプロジェクトに入らず、元動画もアップロードしません。

> 実測：18 秒のお手本動画を 5 ショットに分解。監督が書いた 5 ショットは、ショットサイズとカメラワークが 1 ショットずつ対応していました。約 7 分、GPU 費用はゼロ。

</details>

<details>
<summary><b>5. リメイク</b></summary>

ホームで「リメイク」に切り替え、ダンス動画（2〜15 秒の一部を選ぶか、最長 5 分の通し）、成人キャラクターの全身正面図と顔アップ（AI 生成でも、使う権利のある実在の人物でも）、衣装の説明をひとことアップロードします。起動を承認すると、SAM 3D Body のモーションキャプチャ、Blender の白モデル、MiniMax H3 + 差し替え LoRA が順に走り、3 列の比較動画が出力されます。気に入らなければテイクを追加するか衣装を変えて撮り直せます。モーションキャプチャと白モデルはそのまま再利用されます。通しの場合は、まず冒頭 4.5 秒を何テイクか試し撮りし、1 本選んで「N 本目で全体を作る」を押すと、残りを何パートかに分けて撮り、1 本につなぎます（25 秒のダンスで約 1 時間・¥4〜5。試し撮りの費用も上限に含まれます）。動きと顔は選んだテイクに合わせますが、衣装の細部はずれることがあります。

</details>

## 仕組み

1. **ローカルの監督が段取りを組む**：`dsh` に設定した LLM が脚本を書き、お手本動画の骨格を組み立て、あなたの差し戻し理由に沿って絵コンテを直します。プロジェクトのファイルはすべてローカルの `~/.dsh/shisei/jobs/` に保存されます。
2. **あなたが確認して初めて起動**：映像を生成する前に毎回予想費用を計算し、あなたが「GPU を起動して撮影」を押して初めて、プラグインが [compshare](https://passport.compshare.cn/register?referral_code=4Lx1jWqZk3lBVdaBfXlFAc) の API で 4090 48G インスタンスを起動し、プラットフォーム側の停止タイマーを設定します。
3. **トンネル越しにクラウドのワークフローを呼ぶ**：`ssh` トンネルで、クラウド側で `127.0.0.1` だけをリッスンする ComfyUI（クラウドのワークフローサービス）につなぎ、Qwen-Image（画像生成モデル）、SAM 3D Body、Blender、MiniMax H3 を動かします。
4. **手元に戻してテイクを選び、結合**：生成した画像と動画はローカルに戻ります。あなたが確認しテイクを選んだら、ローカルの `ffmpeg` でラウドネスを揃え、ソフト字幕を埋め込み、透かしなしの MP4 を書き出します。クラウド側は 10 分アイドルが続くと自動で停止します。

## お金・安全・プライバシー

以下のルールはコードに組み込まれていて、オフにできません。

- **起動はあなたのクリックだけ**：「GPU を起動して撮影」を押さない限り、決して起動しません。監督のシェルで起動や課金につながるコマンドはすべて拒否されます。各プロジェクトの予算上限はデフォルト ¥5 で、超えるなら起動しません。
- **画面の概算は請求額より低く出る**：上限のチェックはプラグインが記録した稼働時間で行います。撮影後、マシンは 10 分アイドルが続いてから自動停止し、この間もプラットフォーム側では課金されます。休み休み撮ると差は大きくなります（上の『晾衣绳』を参照）。正しい金額は [compshare](https://passport.compshare.cn/register?referral_code=4Lx1jWqZk3lBVdaBfXlFAc) の請求明細で確認してください。
- **停止するだけ、何も削除しない**：プラグインが行うのはマシンの停止だけで、インスタンスもディスクも削除しません。差し替えた先頭フレームや動画も旧バージョンとして残ります。
- **キャラクターは 18 歳以上**：実在の人物の写真や、実在の人物（著名人を含む）に似せた画像も参考にできます。プラグインは検査も遮断もしません。本人の同意を得ること、現地の肖像権や深層合成の表示義務を守ることは利用者の責任です。「若く見える」とマークしたキャラクターは元の体型のまま、より露出の多い服には替えず、スカートの中を撮るアングルは禁止、ローアングルは膝の高さより下げません。
- **ComfyUI を公開ネットワークにさらさない**：クラウド側は `127.0.0.1` だけをリッスンし、`ssh` トンネル経由でアクセスします。起動のたびに外部からポートが閉じていることを確認し、Shisei 以外が投入したタスクがキューに現れたら警告して一時停止します。キーは `dsh` の認証情報ストアか環境変数にだけ置き、ディスクに書き出さず、画面にも再表示しません。
- **データの送り先は明示**：テレメトリはなく、Shisei 独自のサーバーもありません。データが送られるのは、あなたが設定した次の送り先だけです。[compshare](https://passport.compshare.cn/register?referral_code=4Lx1jWqZk3lBVdaBfXlFAc)（优云智算）の API、あなた自身の GPU インスタンス（`ssh` トンネル経由）、`dsh` の監督モデル、ビジョンモデル（キーを設定した場合のみ、先頭フレーム・抜き出したフレーム・お手本動画のコンタクトシートを送信。お手本の元動画は手元から出ません）、読み取り専用の Shisei 素材ライブラリ（相手にはあなたの IP が見えます）。パソコンに ffmpeg がなければ、dsh に設定した npm レジストリからプラグインの ffmpeg パッケージを 1 回ダウンロードします。お金がかかるのは GPU の秒単位の課金と、監督モデル・ビジョンモデルそれぞれの API 料金だけです。詳しくは [PRIVACY.md](PRIVACY.md)。

## よくある質問

<details>
<summary><b>オンラインの AI 動画サービスと何が違いますか？</b></summary>

オンラインの AI 動画サービスは Web ページを開けばすぐ使えます。`dsh` やクラウド GPU マシンを自分で用意する必要も、2〜3 分のコールドスタートを待つ必要もありません。

Shisei が向いているのは、月額サブスクを払いたくない人、プロジェクトファイルも旧バージョンも自分のパソコンに残したい人です。払うのは映像を生成する数分間のクラウド GPU の秒単位の料金だけ。完成版の映像に透かしはなく、コードはオープンソース。画面に丸を描けば、監督に気に入らないパートだけを撮り直させることもできます。

</details>

<details>
<summary><b>費用はどれくらいかかりますか？</b></summary>

プラグインは無料です。費用が発生するのは 2 か所だけ。GPU の秒単位の課金（上の実測表を参照）と、監督モデル・ビジョンモデルそれぞれの API 料金です（おすすめの Ling-3.2-Flash には無料枠があります）。

</details>

<details>
<summary><b>実在の人物の写真や俳優のスチールは使えますか？</b></summary>

使えます。キャラクターの参考は実在の人物（著名人を含む）でもかまいません。プラグインは遮断しません。本人の同意と、現地の肖像権・深層合成の表示義務は利用者の責任です。完成映像にはウォーターマークを入れず、AI 生成の注記はファイルのメタデータにだけ書きます。アップロード窓口が受け付けるのはシーン・小道具・衣装だけです（衣装替えの経路は服だけを描き直すため）。人物の画像はプロジェクトに参考として置いてください。

</details>

<details>
<summary><b>対応する GPU と OS は？</b></summary>

GPU は 4090 48G。ほかのカードは、実機で `gpu-qualify` を通過したものから順次追加します。OS は macOS と Windows に対応。Windows 11 では、テンプレートのコピーから監督による脚本、完成版までのショートドラマの流れを最後まで通しました（中国語版 Windows 標準の GBK エンコードでも動作）。リメイク、「はじめに」ページでのマシン作成、「環境を更新」は Windows ではまだ検証していません。Linux はロードマップに入っています。

</details>

<details>
<summary><b>プラグインを更新したら、マシンの環境を入れ直す必要がありますか？</b></summary>

必ずしも必要ありません。マシンには独自の環境バージョンがあり、番号が上がるのは入れるもの自体が変わったときだけです。食い違うと監督が教えてくれ、「マシン」ページでもそのマシンに印が付きます。停止してから「環境を更新…」を押してください。価格を確認するとプラグインが起動し、[`setup.sh`](skills/shisei-motion/assets/image/setup.sh) をもう一度実行し（変わった部分だけを補います）、セキュリティチェックの後で停止します。ルールは [docs/IMAGE.md](docs/IMAGE.md) にあります。

</details>

<details>
<summary><b>商用利用できますか？</b></summary>

プラグインのコードは可能です。生成に使うモデルにはそれぞれのライセンスがあり、MiniMax H3 と差し替え LoRA は `minimax-h3-community-license` です。商用利用の前に必ず読んでください（下の「ライセンス」を参照）。

</details>
